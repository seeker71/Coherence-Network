# Retired docs

Pipeline-era readers whose lane left the body. They described the overnight agent-task
pipeline — project manager, monitor, meta-questions, spec-coverage tables, model routing
tiers, runbooks and roadmaps — written February–August 2026 while the Python API carried
the organism. The lane is off by config (`agent_executor.auto_execute` false,
`disable_codex_executor` true), `docs/system_audit/model_executor_runs.jsonl` records no
run of its orchestrators, and no index circulated these docs, so they stand here as history
rather than on the arrival path. What they pointed at lives in the living doors now:
`form/NORTH_STAR.md` (who we are and where we go), `docs/shared/agent-start-packet.md` (the
current floor), `docs/DEPLOY.md` and `docs/PRODUCTION-SUBSTRATE.md` (how the body runs),
`api/config/model_routing.json` (routing as data), `specs/INDEX.md` and `make wellness`
(spec coverage read from the body itself).

Moved 2026-10-20 together with the scripts that read them: `api/scripts/monitor_pipeline.py`,
`project_manager.py`, `run_meta_questions.py`, `build_ai_agent_improvement_plan.py`,
`overnight_orchestrator.py`, `update_spec_coverage.py`, `run_backlog_item.py` and the
`run_overnight_pipeline*.sh`, `ensure_effective_pipeline.sh`, `run_autonomous.sh` wrappers.
`AGENT-ARCHITECTURE.md`, `CURSOR-CLI.md` and `AGENT-PIPELINE-RUN-REPORT-2026-03-06.md` joined
them the same day: nothing linked them and each instructs running the lane that left.
A doc that wants to return is rewritten against the sources that exist, not restored.
