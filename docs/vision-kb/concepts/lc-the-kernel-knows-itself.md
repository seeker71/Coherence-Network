# The Kernel Knows Itself — fkwu as Inspectable Form

The kernel knows itself when its live source, image, symbols, source identity,
native attestation, runtime traces, and JIT bindings can be read as one
attributed Form body. That body is fkwu.

Grammar remains the self-mirror: C source, Form source, BML declarations, and
runtime receipts can enter the lattice as attributed cells. Inspection serves
the live fkwu path—what source built this carrier, what recipe ran, which native
cell or JIT page answered, and where an observed gap belongs.

The former Rust, Go, TypeScript, and Python kernel implementations are bootstrap
history. Their language grammars remain useful for understanding and migrating
source, while their kernels carry no runtime choice, fallback status, or routine
proof burden. A useful discovery moves into fkwu, Form/BML, or the page JIT.

Self-knowledge is operational when an observation returns enough identity to
reproduce the carrier and enough trace to repair the cause. The current native
bundle supplies that identity; the next work deepens attributed runtime/JIT
traces and grounds them in the substrate.
