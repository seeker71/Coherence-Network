# Native Kernel Binary — fkwu Carries the Body

The native kernel binary is `fkwu`. It reads Form source and images, walks the
same recipes the body stores, crosses host I/O through its native cells, and
binds hot compatible recipe shapes to the page JIT. Application behavior stays
in Form or BML; speed changes how that behavior executes, not what owns it.

The operational command door is the fkwu-built `form-cli` bundle. Its source
identity, image, symbols, native attestation, and executable travel together.
Direct arguments and piped input enter one Form REPL, so no host-language verb
router defines the command surface.

Rust, Go, and TypeScript kernel trees record bootstrap validation history. They
do not compete with fkwu, define a fallback, or create a recurring validation
obligation. When their old proof teaches a useful shape, that shape moves into
Form/BML or the fkwu JIT and the duplicate authority retires.

Current work is direct: widen native HTTP dispatch, configuration, persistence,
and database ownership in the fkwu application host; move each application
route into Form/BML; repair each newly observed hot-shape gap in the page JIT.
